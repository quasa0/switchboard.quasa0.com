A few things to know.

Does it change the account in my browser?

No. It selects the login used by new Claude Code or Codex CLI sessions. Your browser and ChatGPT app stay signed into their own accounts. The ChatGPT section shows Codex allowances, not ChatGPT message quotas.

Can I switch during a running coding session?

Close the provider’s sessions before switching. Running clients can keep credentials in memory and refresh tokens. Start a new session afterward. Switchboard does not kill your sessions or move an in-flight conversation.

Where are my credentials stored?

Saved snapshots use macOS Keychain. Account metadata stays in Application Support with owner-only permissions. Isolated CLI profiles can also contain credential files while checking usage. Nothing is uploaded to a Switchboard service. Read the storage details.

Do all subscription plans work?

Switchboard reads the plan and limits your CLI reports. Claude requires Keychain-based login. Codex requires its file credential store. API-key logins and Codex keyring, auto, and ephemeral stores are not supported. Internal provider interfaces can change.

Can I build it myself?

Yes. You need macOS 14+ and Swift 5.10 or newer through Xcode Command Line Tools. Clone the repository and run ./scripts/install.sh. Build instructions ↗
